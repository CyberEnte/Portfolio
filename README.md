# Simon Glisnik - Portfolio

A modern, interactive portfolio website showcasing projects, skills, and fun mini-games with hidden easter eggs!

## 🌟 Features

### Main Sections
- **Hero Section**: Eye-catching introduction with name and tagline
- **About**: Personal information and statistics
- **Projects**: Showcase of top 6 projects with technologies used
- **Skills**: Categorized technical skills (Frontend, Backend, Database, DevOps)
- **Games**: Interactive mini-games section
- **Contact**: Contact form and social media links

### 🎮 Mini Games
1. **Snake Game**: Classic snake game with high score tracking
2. **Memory Cards**: Match pairs of emoji cards
3. **Secret Pong Game**: Hidden Pong game (unlock by clicking name 15 times)

### 🎁 Hidden Features & Easter Eggs

1. **Click Counter**: Click the name "Simon Glisnik" 5 times to reveal a secret click counter
2. **Secret Game Unlock**: Click the name 15 times to unlock a hidden Pong game
3. **Konami Code**: Type the Konami Code (↑ ↑ ↓ ↓ ← → ← → B A) for a Matrix rain effect
4. **Developer Console Messages**: Check the browser console for hidden messages and tips
5. **Console Secret Function**: Type `revealSecret()` in the console to see all hidden features
6. **Glitch Effect**: The name gets a glitch effect after 5 clicks
7. **Smooth Animations**: Scroll-triggered animations throughout the site

## 🚀 Getting Started

Simply open `index.html` in your web browser. No build process or dependencies required!

```bash
# Clone the repository
git clone https://github.com/CyberEnte/Portfolio.git

# Navigate to the directory
cd Portfolio

# Open in browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **Vanilla JavaScript**: Interactive features, games, and easter eggs
- **Canvas API**: Used for Snake game, Pong game, and Matrix rain effect
- **Local Storage**: High score persistence for games
